## Stack and deploy
- Plain static HTML + one style.css, generated by `build.py` (Python standard library only) from `content/*.html`
  fragments (each starts with a `<!--META {json} -->` block: title, description, h1, dates, faq, src, related).
- Built HTML is committed at the repo root. GitHub Pages: Deploy from a branch, `main`, `/` (root). No Actions, same as snakewise.
- Live: https://joshuaofisrael.github.io/pandaswise/
- Relative links everywhere (`@/` in content becomes the right relative prefix); only 404.html uses absolute paths (BASE_PATH).

## Switching to a custom domain (one line + CNAME)
1. In build.py set `BASE_URL = "https://pandaswise.com/"` (planned domain, not bought yet; no CNAME until it is).
2. Add a `CNAME` file containing just the bare domain. Commit once from the repo (avoid snakewise's CNAME churn).
3. `python3 build.py`, commit, `git pull --rebase`, push. Set the same custom domain in Settings > Pages, wait for the cert, Enforce HTTPS.
4. `./indexnow.sh` (key file is regenerated at the new root automatically).
